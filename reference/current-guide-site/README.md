# GuideFS Current Website Migration Pack

Prepared from a public crawl of **https://guidefs.co.uk** on **2026-08-29**.

## Files

- `current-navigation.md` — current menu tree and hidden/legacy pages discovered
- `page-inventory.csv` — spreadsheet-friendly list of current pages and concise content scope
- `current-site-structure.json` — machine-readable navigation, page inventory, global data and external dependencies
- `content-migration-inventory.md` — grouped page-by-page content map for the redesign team
- `global-components-and-data.md` — current contact, office, corporate and reusable global data
- `external-dependencies.md` — WEBPRO calculator, analytics and external portal dependencies
- `source-urls.txt` — source URLs for verification/crawling

## Important limitation

This pack captures the **complete public navigation structure and migration summaries**, but it is **not a verbatim mirror of every page or a download of all media/assets**.

For an exact, lossless migration of text, images, PDFs, metadata and CMS content, obtain a **Drupal export / database backup / public-files archive** from the firm or current provider. That is the correct source for exact content ownership and prevents losing media, SEO fields or unpublished content.

## Recommended use

1. Use the inventory to design the new information architecture.
2. Use source URLs to verify existing SEO URLs.
3. Obtain the Drupal export before cancelling WEBPRO.
4. Rewrite and compliance-review public copy rather than blindly copying the old wording.
5. Preserve or 301-redirect every valuable existing URL during launch.
